# Creesync Software Technologies: website

Static informational website for **Creesync Software Technologies Private Limited**, the company behind FarziEngineer®.

- Pure HTML/CSS/JS with no build step, hosted on GitHub Pages from the `main` branch root.
- Every contact CTA links to https://farziengineer.com/contact-us/
- Images come from the FarziEngineer company profile deck (`assets/img`).
